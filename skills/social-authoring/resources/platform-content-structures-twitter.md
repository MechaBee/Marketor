## Twitter/X Platform

### Twitter Post (tw-post)

Standard single tweet for quick updates, announcements, and engagement.

```markdown
## Post Content

## Main Tweet
[Concise, impactful message - 280 characters max]

[Include hook in first words - visible in previews]

[Optional: mention relevant accounts with @]

---

**Hashtags:** #Hashtag1 #Hashtag2 (1-2 max for best engagement)
**Media:** [Optional: image, GIF, or video reference]
```

**Length Optimization:**
- **Standard limit**: 280 characters
- **Premium/X Premium+**: Up to 25,000 characters (use sparingly)
- **Optimal**: 71-100 characters for highest engagement
- **With media**: Shorter text performs better (let visuals speak)
- **With links**: URL shortened automatically, plan for ~23 chars

**Platform Tips:**
- First words are critical (appear in notifications/previews)
- Questions drive replies
- 1-2 hashtags optimal (more reduces engagement)
- Native images get 150% more retweets than links
- Best posting times: 9am-12pm weekdays
- Threads for complex topics (don't cram into one tweet)

### Twitter Thread (tw-thread)

Multi-tweet thread for storytelling, tutorials, or detailed explanations.

```markdown
## Post Content

## Tweet 1/N (Hook)
[Attention-grabbing opener - this determines thread success]

[Promise value: "Here's what I learned..." / "A thread 🧵"]

## Tweet 2/N
[First point or story beat]

[Keep each tweet self-contained but connected]

## Tweet 3/N
[Second point with supporting detail]

[Use visuals where possible]

## Tweet 4/N
[Third point or example]

[Data, quotes, or evidence strengthen credibility]

## Tweet N/N (Conclusion)
[Summary of key takeaways]

[Clear CTA: follow, retweet, comment, link]

---

**Hashtags:** #Hashtag1 #Hashtag2 (first tweet only)
**Thread Length:** [N] tweets
```

**Length Optimization:**
- **Per tweet**: 280 characters max (aim for 200-250 for readability)
- **Thread length**: 5-15 tweets optimal
- **First tweet**: Most critical - determines if people read more
- **Last tweet**: Include CTA and optional retweet of first tweet

**Platform Tips:**
- Number tweets (1/10, 2/10) for clarity
- 🧵 emoji signals "this is a thread"
- Each tweet should work standalone
- Add visuals every 2-3 tweets
- End with CTA and self-retweet option
- Pin threads to profile for visibility
- Best for: tutorials, stories, analyses, lists

### Twitter Reply (tw-reply)

Strategic reply tweets for engagement and conversation building.

```markdown
## Post Content

## Reply Context
**Replying to**: [@username or tweet reference]
**Intent**: [engagement | support | question | value-add]

## Reply Text
[Thoughtful response adding value to conversation]

[Keep concise - replies should feel conversational]

---

**Hashtags:** [Usually none in replies]
```

**Length Optimization:**
- **Optimal**: 50-100 characters
- **Maximum**: 280 characters
- **Note**: @mention counts against character limit

**Platform Tips:**
- Replies build relationships and visibility
- Add value, don't just agree
- Ask follow-up questions
- Avoid hashtags in replies (looks spammy)
- Quick replies get more visibility
- Great for building authority in niche topics

## Character Limits Summary

| Element | Limit |
|---------|-------|
| Tweet (standard) | 280 characters |
| Tweet (Premium) | 25,000 characters |
| Display name | 50 characters |
| Username | 15 characters |
| Bio | 160 characters |
| Hashtags | No limit (1-2 recommended) |
| Media | 4 images, 1 video, or 1 GIF |

---

## Hashtag Strategy

| Count | Strategy |
|-------|----------|
| **0-1** | Best for conversational tweets, replies |
| **1-2** | Optimal for reach without looking spammy |
| **3+** | Only for specific campaigns or trending topics |

**Best Practices:**
- Research trending hashtags in your niche
- Create branded hashtags for campaigns
- Avoid hashtag-stuffing (reduces engagement)
- Place hashtags at end or integrated naturally
- Check hashtag meaning before using (avoid hijacking)

## CTA Patterns

| CTA Type | Example |
|----------|---------|
| **Engagement** | "Reply with your take 👇" |
| **Follow** | "Follow for more [topic] content" |
| **Retweet** | "RT if you agree" / "Share with someone who needs this" |
| **Link** | "Full article: [link]" / "Link in bio" |
| **Thread** | "Read the full thread 🧵" |
| **Quote** | "Quote tweet with your experience" |
